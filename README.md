# prumo-api

API do **Prumo**, o coach de bem-estar com IA que responde "como estou hoje?". Projeto do FMU Tech Inovação 2026.2, ODS 3.

A proposta, as regras de pontuação e a arquitetura ficam no repositório central [Health-Prumo/prumo](https://github.com/Health-Prumo/prumo).

**Status:** em preparação para o Checkpoint 2. Stack definida: Python, AWS Lambda, API Gateway, DynamoDB e Amazon Bedrock (Nova Micro). Detalhes para quem for contribuir (pessoas ou agentes de IA) em [AGENTS.md](AGENTS.md).
